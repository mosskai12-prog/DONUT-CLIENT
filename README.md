# DONUT CLIENT

A client-side Fabric utility mod for Minecraft Java 1.21.11.

## Current modules

- **Fullbright** — raises gamma while enabled and can restore the previous gamma value.
- **Toggle Sprint** — automatically sprints while moving forward, with configurable forward/sneak behavior.
- **Coordinates HUD** — displays block X/Y/Z coordinates.
- **FPS Counter** — displays the current frame rate.

## Controls

- **Right Shift** — open or close the ClickGUI.

## Build

The GitHub Actions workflow builds with Java 21 and Gradle 9.2.1. Download the JAR from the workflow's Artifacts section after a successful build.

## Configuration

Module states, favorites, and settings are saved in `.minecraft/config/donutclient.properties`.
